What is ParallelStencil.jl? ​

ParallelStencil empowers domain scientists to write architecture-agnostic high-level code for parallel high-performance stencil computations on GPUs and CPUs. Performance similar to CUDA C / HIP can be achieved, which is typically a large improvement over the performance reached when using only CUDA.jl or AMDGPU.jl GPU Array programming. In conjunction with ImplicitGlobalGrid.jl, the same Julia code can run on a single CPU thread or on thousands of GPUs/CPUs. See the Overview for more details.

Installation ​

ParallelStencil can be installed directly with the Julia package manager from the Julia REPL:

julia
import Pkg; Pkg.add("ParallelStencil")

Dependencies ​

ParallelStencil relies on the Julia packages CUDA.jl [1, 2], AMDGPU.jl, Metal.jl, KernelAbstractions.jl, Polyester.jl, MacroTools.jl, CellArrays.jl, StaticArrays.jl and Enzyme.jl. However, thanks to Julia's package extensions, only CellArrays.jl, MacroTools.jl and StaticArrays.jl are fixed dependencies that are automatically installed with ParallelStencil; the other packages are only required when using the respective backends or features.

Contributing ​

Contributions are welcome, be it new miniapps, math-close notation for other numerical methods (see the tiny FiniteDifferences1D submodule as an example), convenience features or core improvements! Please open an issue to discuss your idea beforehand. A pull request should address an issue in its completeness and blend nicely into the existing project (community guidelines such as ColPrac can serve as inspiration).
